# DyqaniOnline.Java

Ky sistem eshte nje aplikacion ne Java per menaxhimin e nje dyqani online ,i cili mundeson menaxhimin e produkteve ,klienteve, shportes, porosive dhe pagesave.Sistemi pergadit cmimet dhe aplikon zbritjet e kombinuara per artikuj te caktuar qe perfshihen ne oferte duke e bere me te sigurt aplikimin.Platforma perdoret nga klientet per te pare produktet dhe kryerjen e porosive si dhe nga administratoret/stafi per menaxhimin e sistemit.
